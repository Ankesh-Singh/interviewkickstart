# Interview Kickstart - Landing Page Revamp

A landing page implementation for Interview Kickstart built with Next.js (App Router), TypeScript, and Tailwind CSS. Built as a technical assignment submission.

## Tech Stack
- Next.js 16 (App Router)
- React 19 & TypeScript
- Tailwind CSS

## Getting Started

```bash
pnpm install
pnpm run dev
```

## Production Build

```bash
pnpm run build
```

## Deploy to Cloudflare Pages

1. Push this repository to GitHub.
2. In Cloudflare Pages, select **Create a project → Connect to Git** and choose the repository.
3. Set the build command to `pnpm run build` and the output directory to `out`.
4. Deploy. Future pushes to `main` deploy automatically.
