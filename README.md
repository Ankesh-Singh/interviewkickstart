# Interview Kickstart - Landing Page Revamp

A landing page implementation for Interview Kickstart built with Next.js (App Router), TypeScript, and Tailwind CSS. Built as a technical assignment submission.

## Tech Stack
- Next.js 16 (App Router)
- React 19 & TypeScript
- Tailwind CSS

## Getting Started

```bash
pnpm install
pnpm run dev
```

## Production Build

```bash
pnpm run build
```
